# 界面约定与本次审查

2026-11-01。沿用现有 Tauri 2、Rust、React/TypeScript、Lucide 和 CSS 变量；功能、数据、文件归属、预览确认、任务调度及窗口状态仍以实施合同为准。本文件整理已有方向，不要求下载安装设计工具或字体。

## 已确认方向

- 按用户追加授权调整主题与风格：明亮采用冷灰层次，夜间采用 ChatGPT 方向的分层石墨灰，护眼采用较暗的暖鼠尾草灰。保持三种用途，分别协调四种强调色和分类颜色。颜色区分语义，状态还须有文字或图标；不以颜色独立表达错误、选择或可用性。
- 沿用用户字号、Ctrl＋滚轮缩放、紧凑／舒适密度和动效选择；使用现有系统字族，不下载字体。正文、辅助文字、控件及焦点保持可辨，不用降低透明度掩盖状态。
- 一页一个主标题；顶部固定侧栏开关，单份真实导航跨业务标签共用。分类、历史、标签和内容各在适当范围滚动；长名称与路径提供完整内容入口。
- 工作台以搜索、筛选、名称、状态和操作为主，次要动作并入工具条。分类标签优先换行，不挤掉名称；窄窗允许正常横向滚动，操作列不盖住内容。
- 设置按功能分组，短小独立设置左文右控；连续填写的凭据、代理和路径表单保持标签在上。以间距、标题和轻分隔区分组，不堆叠大卡片。
- 安装、上传、更新、授权与卸载的步骤和确认边界保持。主操作随当前阶段清楚呈现，危险动作与普通操作区分；精简文案不能删除权限或影响范围说明。
- 读取、保存、测试连接是不同结果。错误给出对应操作和可采取的下一步，保留原始原因；失败不显示为成功，不自动重放写入。
- 说明页采用阅读层级和目录，操作页采用稳定控件和紧凑工具条。只对真实瓶颈优化，沿用本地优先、按需加载及有界缓存，不加入展示性材质或动画。

## 本次实际发现与处理范围

| 问题 | 处理 |
|---|---|
| 工具页外层和内部重复主标题 | 嵌入时保留外层唯一主标题，独立组件继续有标题 |
| 类型筛选继承全宽，工具条被拆成多行 | 限定类型控件宽度，搜索优先，窄窗自然换行 |
| 没有保存视图时单个按钮独占一行 | 并入筛选动作；编辑草稿和反馈继续全宽，实例与功能保持 |
| 设置分组和卡片覆盖规则重复 | 整理实际分组样式，保留目录、滚动及窄窗变量 |
| 网络设置初次读取失败后无法继续 | 提供原地重新读取；区分读取、保存及连接测试反馈 |
| 主题背景、输入与浮层缺少区分 | 中央变量重配三主题及四强调色；保留语义与分类色、字号和缩放，主题预览同步 |
| 同一包流程的限速单位不一致 | 界面统一 MiB/s，后端仍为精确整数 B/s；非法或过小正数不能变成不限速 |

主体阶段已修复的表格遮挡、长分类挤名称、高缩放分类区空间与任务结果丢失继续保留。变更后的实际验证结果写入开发进度，不凭本约定宣称界面通过。

## 在线参考与适用边界

### 总览的界面约定

总览采用四个小型可点击统计及双列内容，窄窗自然变单列。统计区区分Skills、工具、待处理Skill和后台任务；主内容为待处理、收藏、任务、来源、分类及近期操作。复用同一来源和问题判定，资源正常时直接显示简短结果；检查失败显示实际原因，未知数量使用占位符。分类沿用用户颜色，状态使用语义色，文字和焦点沿用既有高对比主题。

总览无独立轮询或远端扫描。工具目录复用按状态版本失效的共享本地元数据缓存，访问总览仅补读必要元数据。历史限定为保留记录，不推测完整使用率。问题进入文件页、收藏进入说明、来源进入对应设置组、任务进入既有记录，保持写操作预览与权限规则。

## 用户审阅后的布局方向 — 2026-11-01

用户明确选择“ChatGPT 式简洁框架＋Skills Manager 卡片与彩色分类”，并指出设置页仍杂乱。本轮采用九个实际设置分组（常规、外观、维护、场景、保存位置、网络、GitHub、配置导入导出、诊断），一次显示一组。每组首次访问才加载，已访问组件保留挂载，隐藏组不可聚焦，未保存输入和业务状态跨分类保留。隐藏的场景、维护、配置、诊断和保存位置组暂停相关读取。旧设置锚点及快捷入口继续对应，分组位置独立记忆。

卡片以名称和收藏为首行、两行简介、彩色分类和文字状态、来源／版本／连接及底部选择／动作构成。保留列表与详情视图、批量选择、键盘、拖动归类及完整来源查看。工作台统计贴近主标题，搜索和卡片对齐；系统现有无衬线字体、品牌字阶、导航节奏及普通按钮层级统一，不下载字体，不用复杂材质。GitHub 凭据移除单独说明本机范围，调用逻辑保持。

用户已确认沿当前总览方向继续完善并验收。完成当前修改后构建候选并核对受影响流程，旧候选的界面结果按实际改动范围复用，新的布局与性能须使用对应候选验证。

分组保存只提交所属字段：常规保存编辑器，外观保存主题、字号、强调色、密度和动效；切组不把另一组的预览隐式保存。分类开关保持在独立上方同一入口，宽窄屏均可收起，收起后释放导航列；不新增内容滚动区。这两项复查修正先保留于源码，不替换用户在用预览，设计反馈后再构建并验证。

全局侧栏两态共用品牌占高、导航图标列、起点、行高及间距；品牌文字不以换行推移导航，完整名称保留查看入口。小高度规则和密度调整同时作用于两态。设置的标题与内容在宽度足够时使用同一稳定窗口基准，避免随着侧栏宽度重新居中；窄窗口先保证内容可达，不能为固定位置而遮挡内容。验收须比较实际导航坐标、顶部开关、文字字号和窄窗浮层，CSS推导不能替代运行证据。

统一资源列表复用已登记身份，按类型区分同名条目，分页及筛选保持阅读位置。总览统计在中宽窗口保持紧凑四列，窄窗口切换两列；较低窗口统一收紧两态导航行，为分类保留空间。跨页输入以当前用户操作为准，较早的页面保存回复不能重新导航；明确页面跳转以新的工作区修订标识应用。

正常统计不重复说明可点击行为，保留真正影响判断的加载、失败与过期信息；数字和必要提示同行且允许换行。近期操作范围放在标题旁，来源只显示检查时间或异常。简短只读设置采用左侧名称与说明、右侧当前值，不另堆叠说明卡片。

## 总览与设置导航 — 2026-11-24

总览统计合并成一条可点击的摘要带，按内容区宽度切换列数。内容用一份按行阅读的网格，宽窄窗、键盘和视觉顺序一致：先处理和收藏，再看运行任务和 GitHub 来源，最后看记录与分类。分类继续使用用户设定的颜色，状态保留文字。待处理、任务、历史、分类等均继续读取原有快照。

## iOS 27 材质与操作反馈 — 2026-11-24

工具栏、选中页签和弹层使用静态细边与协调圆角。实色总览与设置页面始终清晰。快捷入口在浏览器支持且允许透明度时使用 94% 实色混合与 8 px 局部模糊；减少透明度、增强对比或强制颜色时用实色。普通对话框依靠遮罩和实色主体区分层次。

沿用现有动效选择。有效动效开启时，快捷入口从 4 px 小范围入场，目录箭头和少量工具栏图标提供 150 ms 反馈。焦点、键盘和关闭同时可用，滚动、导航布局、后台任务与进度值不靠动画改变。参考见 [iOS 27 材质与动效](SOURCES.md#ios27-desktop-material-20261124)。

检查、分类等操作菜单与列表快捷键共用实色浮层、可辨边框和内外两级圆角。浮层定位后才播放 150 ms 淡入，菜单和快捷键可立即关闭或用键盘操作。关闭动效、跟随系统减少动效、增强对比或强制颜色时，菜单与列表快捷键直接显示。目录和分类开关通过当前主题的选中色表达展开状态，强制颜色下以系统轮廓表达，继续保留焦点样式及按钮坐标。菜单达到极窄可用宽度时随视口收缩。

工作区快捷键、窄窗目录和侧栏、操作对话框及详情抽屉沿用实色浮层。轻量淡入只改变不透明度，几何位置和键盘输入立即生效；工作区快捷键按窗口可用高度滚动。分段控件通过抬高的选中底色、清晰文字和高对比轮廓区分当前项。参考见 [Apple 分段控件与动效](SOURCES.md#ios27-desktop-material-20261124)。

独立 Skill 说明优先呈现正文和阅读目录。原本占用首屏的概况和操作可以原位展开，错误及待核对状态仍直接可见。「文件」「来源与连接」和库内详情抽屉继续直接显示原有工具栏。原始 YAML 声明单独展开，正文的链接、代码和标题按既有阅读样式呈现。
